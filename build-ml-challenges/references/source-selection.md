# Source selection

Most candidate datasets fail. Reject fast and cheaply: screen the name, then
the card, then the content. Only download what survives all three.

## Reject from the name alone

These substrings are decisive; do not open the page.

| Substring | What it means |
| --- | --- |
| `sft`, `rl`, `rlhf`, `dpo`, `preference`, `instruct`, `chat`, `sharegpt`, `agent`, `tool`, `trajectory` | LLM post-training data |
| `corpus`, `pile`, `pretrain`, `raw-text` | Pretraining corpus — no labels at all |
| `benchmark`, `bench`, `eval`, `arena`, `leaderboard` | An existing benchmark, often with a live leaderboard |
| `sample`, `demo`, `toy`, `mini`, `debug`, `test`, `part`, `shuffle` | Someone's working artifact, not a release |
| `uncensored`, `roleplay`, `nsfw` | Content policy will block platform approval |

**Why LLM data never works.** It fails three gates simultaneously and no
configuration repairs it: responses are model-generated (no authoritative
answer key), the task requires a pretrained LLM (banning them makes the task
impossible; allowing them makes contamination decisive), and the full data
including answers is public. This single category accounts for the majority of
rejected candidates.

## Reject from the card

| Signal | Why it fails |
| --- | --- |
| "uses the default template" | No description, no license, no provenance to verify |
| `Gated` badge, or "agree to share your contact information" | Download permission is not redistribution permission |
| No License section at all | The license gate requires verification, not absence of evidence |
| `NC`, `ND`, "non-commercial", "research purpose only", "academic use only" | Fails commercial-use and redistribution requirements |
| A long "data sources" table | Composite licensing; the strictest source governs the whole |
| Personal account, 0 downloads, no description | Private storage, not a published dataset |
| No counts stated anywhere | Cannot assess scale; usually means the uploader never looked |

Read `NOTICE` when present — that is where borrowed components are declared,
and where a permissive top-level label is most often contradicted.

## Reject after reading the content

- **Answers generated by a model** (GPT-4, GLM-4, an LLM judge, a reconstruction
  network). The answer key must exist independently of any AI.
- **No target column.** Check the actual schema, not the prose.
- **Answers findable on the internet.** If the task is answerable from Wikipedia
  or a search engine, allowing search trivializes it and banning search makes it
  impossible.
- **Inflated units.** Count independent units, not rows: 35 language variants of
  541 prompts is 541 units; 36 renders of one CAD model is 1 unit; 4,160
  utterances from 10 speakers is 10 units when the task is speaker-disjoint.
- **Third-party copyright in the content itself.** Artwork, olympiad problems,
  published books, and film stills carry rights the uploader does not hold,
  whatever license covers the annotations.
- **Git LFS pointers.** A 134-byte `.tar` is a placeholder. Check with `du -sh .`
  before concluding the data is present; fix with `git lfs install && git lfs pull`.

## Where to look instead

General-purpose model hubs are optimized for LLM artifacts; browsing their front
pages returns the rejected category almost exclusively. Prefer sources whose
primary output is measurement.

| Source | Why it works |
| --- | --- |
| Zenodo, Figshare, Dryad | Data deposited alongside papers; CC-BY and CC0 are the norm |
| Papers with Code, and 2024+ papers with a GitHub release | Recent, niche, rarely benchmarked, license usually in-repo |
| LILA BC (wildlife camera traps) | CC0/CC-BY, large, objective detection targets |
| Roboflow Universe | Object detection with per-dataset licensing filters |
| UCI ML Repository, OpenML | Tabular tasks with objective targets |
| Government open data portals | Public-domain by statute in most jurisdictions |
| Radiant MLHub and other Earth-observation archives | Sensor imagery, no artistic copyright |

On a model hub, filter rather than browse: select task types such as
`object-detection`, `image-segmentation`, `image-classification`, `tabular-*`,
or `time-series`, and license `cc0`, `cc-by-4.0`, `mit`, `apache-2.0`. Exclude
`text-generation` entirely.

## What a passing candidate looks like

Measurement or observation data from a single source with an unambiguous
permissive license, at least 1,000 independent units, an objective target a
machine can verify, obscure enough that no solver can look up the answer,
modest in size, and ideally published after 2024. Imagery captured by
instruments — satellite, microscope, camera trap, industrial inspection,
rendered CAD — avoids the artistic-copyright problem entirely.

## Verify recommendations, including your own

A recommendation from memory is a hypothesis. The Fusion 360 Gallery Dataset is
published by Autodesk with a paper and looks institutionally sound; clause 1 of
its license restricts use to non-commercial research and clause 2 forbids
redistributing it in full. Open the primary `LICENSE` file before proposing any
source.
